反悔贪心（Regret Greedy）

一、动机与背景

1.1 贪心的失效

贪心算法每一步都做出当前最优的选择，但当问题存在 配额（quota）约束 时，早期的一个贪心决策可能阻碍后续获得全局更优的解。

用数学语言描述：设 SSS 为元素集合，每个元素 iii 有两个代价 ai≤bia_i \le b_iai​≤bi​，最多 KKK 个元素可以享受 aia_iai​ 的低代价。贪心策略若先固定享受 aia_iai​ 的 KKK 个元素，再考虑其余的，则可能由于 已选元素本身不优 而无法达到全局最优。

"经典失效场景"

选择 aia_iai​ 最小的 KKK 个元素，但其中某些元素的 bi−aib_i - a_ibi​−ai​ 过小（甚至为 000），导致配额被浪费，而后面本应享受配额的元素反而无法获得。

1.2 反悔贪心的思想

反悔贪心在普通贪心的基础上引入 撤销机制：允许将某个已获得配额的元素 降级，让出配额给更优的元素，同时通过 堆 来维护降级带来的额外代价。

从另一个角度看，反悔贪心等价于维护一个大小为 KKK 的 可替换集合，并动态维护集合中"最差"的那个元素以备替换。

二、形式化定义

2.1 问题模型

给定 NNN 个元素，每个元素 iii 有两个代价 ci≤dic_i \le d_ici​≤di​，以及 KKK 个 升级特权（使用特权时代价为 cic_ici​，否则为 did_idi​）。在总预算 MMM 内最大化选取的元素个数。

等价形式：每个元素 iii 的基础代价 did_idi​，使用特权后减免 si=di−cis_i = d_i - c_isi​=di​−ci​，最多 KKK 次减免。

2.2 反悔机制

记已使用特权的元素集合为 UUU（∣U∣≤K|U| \le K∣U∣≤K）。当考虑新元素 jjj 时：

cost⁡(j)=min⁡ ⁣(dj,  min⁡i∈U(cj+si))\operatorname{cost}(j) = \min\!\Bigg( d_j,\; \min_{i \in U} \big( c_j + s_i \big) \Bigg)cost(j)=min(dj​,i∈Umin​(cj​+si​))

其中 min⁡i∈Usi\displaystyle \min_{i \in U} s_ii∈Umin​si​ 可以通过维护一个小根堆 HHH（存储 {si∣i∈U}\{s_i \mid i \in U\}{si​∣i∈U}）在 O(log⁡K)O(\log K)O(logK) 时间内获得。

当选择特权方式（即 cj+min⁡si<djc_j + \min s_i < d_jcj​+minsi​<dj​）时，执行替换：

  1. 从 UUU 中移除 i∗=arg⁡min⁡sii^* = \arg\min s_ii∗=argminsi​（堆顶出堆）
  2. 将 jjj 加入 UUU（sjs_jsj​ 入堆）

??? tip "堆的初始化"
- 若 KKK 个特权一开始均可自由使用，则堆中预填 KKK 个 000（表示"免费撤销、不损失任何减免"）
- 若特权需要满足某种条件才能获得，则堆初始为空，每当获得一个新特权时才入堆

3.2 正确性要点

"正确性依据"

该算法本质上是 拟阵（Matroid）贪心 的推广：

  • 所有元素构成一个 拟阵，独立集为任意大小不超过 KKK 的特权使用集合；
  • 每次选择"增加代价最小"的元素，并维护拟阵的独立集性质；
  • 堆中存储的 sis_isi​ 实际是该元素加入独立集后带来的 边际代价。

当特权替换的代价可精确计算时，该贪心给出全局最优解。

五、堆的选择策略

堆类型 用途 理论依据
小根堆 维护"最应被替换的元素"——权值最小的 sis_isi​ 替换时需最小化额外代价 cj+min⁡sic_j + \min s_icj​+minsi​
大根堆 维护"收益最大的元素"——选最有价值的替换目标 替换时需最大化总收益

命题：若算法正确，替换操作总是移除 UUU 中 sis_isi​ 最小（小根堆）或收益 最大（大根堆）的元素。移除的准则取决于问题的最小化或最大化目标。

六、与 WQS 二分的关系

反悔贪心也可视为 WQS 二分（Alien's Trick） 的离散模拟：

  • WQS 二分引入参数 λ\lambdaλ 作为特权使用的额外成本，通过二分 λ\lambdaλ 来控制特权使用数量
  • 反悔贪心通过堆来直接 显式维护 替换代价，无需二分
反悔贪心: min⁡si⟷WQS: λ\text{反悔贪心: } \min s_i \quad\longleftrightarrow\quad \text{WQS: } \lambda反悔贪心: minsi​⟷WQS: λ

两者本质等价，但反悔贪心的常数更小，实现更简洁，适用于 NNN 较小但 KKK 较大的场景。

八、边界与细节

"堆空检查"

当 K=0K = 0K=0 或所有特权均已使用时，HHH 可能为空。此时只能选择 dmin⁡d_{\min}dmin​ 路径，务必在使用 H.top()H.\text{top}()H.top() 之前检查 H.empty()H.\text{empty}()H.empty()。

"特权零节省"

当 si=0s_i = 0si​=0 时，元素 iii 使用特权无任何收益。将此元素加入 UUU 会浪费一个配额，且堆中出现 000 导致后续替换的额外代价为 000，可能触发不公平的替换。建议：

  • 预处理：将 si=0s_i = 0si​=0 的元素视为无特权需求的元素
  • 或让堆中的 000 在替换时自动流动（双堆模型天然支持）

"初始占位可能买错"

模型 A 第一阶段可能将配额分配给不值得选取的元素，导致预算被锁死。此时应改用模型 B。

九、思维总结

反悔贪心的本质是 在贪心决策的基础上增加一个"撤回"的选项，使得算法可以在保持 O(Nlog⁡N)O(N \log N)O(NlogN) 复杂度的同时，处理原本需要 O(NK)O(NK)O(NK) DP 才能求解的一类问题。

判断三要素

  1. 存在配额 KKK —— 否则是普通贪心
  2. 替换有可计算的代价 —— 否则无法维护堆
  3. 决策具有单调性 —— 早期的决策在后期不会变得更好（否则需要 DP 而非贪心）

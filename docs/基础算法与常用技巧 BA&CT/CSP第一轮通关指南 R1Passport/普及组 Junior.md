## 1. 计算机基础（初赛专属，复赛完全用不到）

### 1.1 计算机组成

- **CPU** = 运算器（ALU）+ 控制器（CU）+ 寄存器组。ALU 负责算术/逻辑运算。
- **内存（RAM）** 断电数据丢失；**外存**（硬盘、U 盘）断电保留；Cache 是 CPU 与内存之间的高速缓冲。
- 存储层次：寄存器 > Cache > 内存 > 外存（速度递减、容量递增、单位成本递减）。

!!! warning "易错点"
    - "ALU 属于 CPU 的一部分"是经典送分/送命题（SCP2026 考过）。
    - 文件存在外存上，程序**运行时**才调入内存；"关机后数据还在"说的是外存。

### 1.2 操作系统与文件命令（Linux 为主）

| 命令 | 作用 | 备注 |
|:-----|:-----|:-----|
| `pwd` | 显示当前目录 | |
| `cd` | 切换目录 | `cd ..` 上一级 |
| `ls` | 列出文件 | |
| `mkdir` | 新建目录 | 多层需 `mkdir -p` |
| `rm -r` | 递归删除 | 慎用 |
| `cp` / `mv` | 复制 / 移动（重命名） | |
| `g++ a.cpp -o a` | 编译 | 头文件不参与编译 |

- 路径：`/` 根目录，`.` 当前目录，`..` 父目录，`~` 当前用户家目录，`-` 上次所在目录。
- **绝对路径**以 `/` 开头；**相对路径**从当前目录出发。

!!! warning "易错点"
    `~` 表示**当前登录用户**的家目录，不等于别人的家目录。例如当前用户在 `/home/luogu`，`mkdir ~/sjtu/phd/paper` 会建到 `/home/luogu/...` 而不是 `/home/sjtu/...`（SCP2026 考过）。
    做题方法：把命令翻译成"起点 + 操作 + 目标路径"再核对。

!!! tip "编译命令（SCP2025 考过）"
    `g++ -o luogu luogu.cpp`：**源文件 `.cpp` 放最后，`-o` 后面紧跟输出文件名**。写成 `g++ -o luogu.cpp luogu` 就把输出名和源文件搞反了。
    编译语言（C/C++）先编译成可执行文件，**编译一次即可反复运行**；解释语言（Python 等）由解释器逐句翻译执行，每次运行都要"翻译"一遍，但无需单独编译。

### 1.3 位、字节、字

- 1 字节 = 8 位（bit）；1KB = 2¹⁰ B = 1024 B；字长 = CPU 一次处理的位数（32 位/64 位）。

### 1.4 进制转换（初赛高频）

- 二转八：**3 位一组**；二转十六：**4 位一组**（高位不足补 0）。
- 十六进制 A~F 对应 10~15，例如 $(1C)_{16}=1\times16+12=28$。
- 十进制转其他进制：**除基取余、倒序写**。
- 混合进制加减（CSP-J 2025 考过 $720_{10}+270_8=388_{16}$）：**全部先转十进制，算完再转目标进制**。
- k 进制数按**位权展开**：$(4321)_k=4k^3+3k^2+2k+1$（SCP2025 考过）——最高位在最左，指数从右往左从 0 递增。

!!! tip "口算技巧"
    背熟 $2^{10}=1024$、$0x10=16$、$0x100=256$、$0x400=1024$。二进制高位连续 1 的速算：$(1111)_2=15$，$(11111111)_2=255$。

### 1.5 原码 / 反码 / 补码（重灾区）

- 正数：原码 = 反码 = 补码；负数补码 = 原码**取反 + 1**。
- $n$ 位补码范围 $-2^{n-1}\sim 2^{n-1}-1$：32 位 `int` 约 $\pm2.1\times10^9$，无符号最大 $2^{32}-1\approx4.3\times10^9$。
- $-1$ 的 32 位补码 = `0xFFFFFFFF`，按无符号解释就是 4294967295。
- **类型转换/溢出 = 按位重解释**：
  - 无符号值 $\ge 2^{31}$ 强转 `int` 时，等于原值减 $2^{32}$；
  - 无符号视角的和 $\ge 2^{31}$ 时，按有符号重解释为负数（如 `unsigned 2147483648 + 1234567890` 按 `int` 输出为 $-912915758$）。

!!! warning "两大坑"
    - 有符号与无符号**混合运算**时，有符号会**自动转成无符号**（不是反过来），这是编译期常见坑。
    - 看到"输出 `int(x)` 的值"先想"$\ge 2^{31}$ 就减 $2^{32}$"。

!!! tip "手算三例（SCP2025 原题）"
    - $-17$ 的原码：$|{-17}|=17=(00010001)_2$，最高位补符号位 1 → `10010001`；
    - $22$ 的补码：正数补码 = 原码 → `00010110`；
    - $-13$ 的反码：$13=(00001101)_2$ 按位取反 → `11110010`。
    流程固定：先写绝对值的二进制 → 按需取反（反码）/ 取反加一（补码）→ 补符号位。

### 1.6 ASCII

- `'A'=65`、`'a'=97`、`'0'=48`；`'a'-'A'=32`。
- 数字字符转数字：`c - '0'`。
- `'0' ^ 1 == '1'`（异或 1 恰好翻转字符 0/1，SCP2026 阅读程序考过）。

### 1.7 网络与 CCF 常识

- 了解 IP 地址、域名、HTTP/HTTPS 等基本概念即可（偶尔一题）。
- CSP-J/S 由 **CCF** 主办，分第一轮（初赛，闭卷）与第二轮（复赛）。初赛**禁止使用任何电子设备与外部资料**，更不可能允许用 LLM 做题。

## 2. C++ 语言（语法细节是区分度来源）

### 2.1 基本类型大小（64 位平台）

| 类型 | 字节 | 范围速记 |
|:-----|:----:|:---------|
| `char` | 1 | -128 ~ 127 |
| `bool` | 1 | true / false |
| `short` | 2 | 约 ±3.3 万 |
| `int` | 4 | 约 ±2.1×10⁹ |
| `long long` | 8 | 约 ±9.2×10¹⁸ |
| `float` | 4 | 有效数字约 7 位 |
| `double` | 8 | 有效数字约 15~16 位 |
| 指针 | 8 | 64 位下 |

!!! warning "易错点"
    - 标准只保证 `1 == sizeof(char) ≤ sizeof(short) ≤ ... ≤ sizeof(long long)`，**不保证具体值**；Windows 下 `long` 是 4 字节，Linux 下是 8 字节。
    - `sizeof(a)/sizeof(a[0])` 求数组长度；`sizeof(指针)` 永远是 8，不是数组长度。

### 2.2 溢出与类型提升

- `int` 相乘可能溢出，习惯写 `1ll * a * b`。
- `1 << n`：$n\ge31$ 时是未定义行为；计算 $2^k$ 用 `1ll << k`。
- 混合运算中 `int + unsigned` 结果是无符号。

### 2.3 位运算（初赛最爱）

| 操作 | 含义 | 典型用途 |
|:-----|:-----|:---------|
| `x & (x-1)` | 消掉最低位的 1 | 判断 2 的幂；配合循环数 1 的个数 |
| `x & 1` | 取最低位 | 判断奇偶 |
| `x >> k & 1` | 取第 k 位 | 状态压缩 |
| `x ^ 1` | 翻转最低位 | 0/1 状态切换 |
| `x << k` / `x >> k` | 乘 / 除以 $2^k$ | 快速缩放（非负整数） |

- 逻辑运算**短路**：`a && b` 中 `a` 为假则不算 `b`；`a || b` 中 `a` 为真则不算 `b`。可用来避免除零、越界。

!!! tip "高频题"
    `int x=255; cout << (x & (x-1));` 输出 254（CSP-J 2025 原题）——`255=0b11111111`，消掉最低位 1 得 `0b11111110=254`。

### 2.4 switch 的穿透（fall-through，SCP2025 考过）

```cpp
switch(x) {
    case 1: { cout << "A"; break; }   // x=1  → 输出 A
    case 3: { cout << "C"; }          // x=3  → 输出 C，无 break 继续向下
    default: { cout << "Q"; }         //       → 输出 Q
    case 5: { cout << "E"; }          //       → 输出 E
}
```

- **执行流从命中的 case 一路向下，直到遇到 `break` 或 switch 结束**：`x=3` 输出 `CQE`，`x=2`（走 default）输出 `QE`，`x=5` 输出 `E`。
- 坑点：**漏写 `break` 是最常见的 bug**，阅读程序专门考"x 取哪些值、输出什么"。
- 建议：从命中的 case 起，画一条执行流往下走，直到 `break` 或 `}`。

### 2.5 引用与指针（坑点之王）

```cpp
int A = 1, B = 1;
int& a = A, b = B;   // 只有 a 是引用！b 是普通 int
a = 2, b = 2;
cout << A << ' ' << B;   // 输出 2 1
```

!!! warning "铁律"
    **修饰符只作用于声明的第一个变量**：`int& a, b;` 只有 `a` 是引用；`int* p, q;` 只有 `p` 是指针。分开声明最安全。
    传引用参数会改实参，传值不会（CSP-J 2025 考了传引用后 x、y 的值）。

### 2.6 递归

- 三要素：**递归边界 + 递归式 + 规模减小**。没有边界或边界写错会无限递归/栈溢出。
- 记忆：递推是自底向上，递归是自顶向下。

### 2.7 string 与字符数组

- `string` 支持 `+` 拼接（`string+string`、`string+char` 均可），`length()/size()`、`substr(pos,len)`（越界自动截到末尾）。
- 字符数组以 `'\0'` 结尾：`strlen` 不含 `'\0'`，`sizeof` 包含。

### 2.8 STL 入门

- 栈：`push/pop/top/empty`（LIFO）；队列：`push/pop/front/back/empty`（FIFO）。
- `vector`、`sort`、`min/max/swap`。
- **空栈上调用 `top()`/`pop()` 是未定义行为**，必须由调用方保证非空。

## 3. 数据结构

### 3.1 栈与队列

- 栈应用：括号匹配、后缀表达式求值、函数调用、DFS；队列应用：BFS、逐层处理。
- **双栈模拟队列**：入队压入 `s1`；出队时若 `s2` 空，把 `s1` 全部倒入 `s2`（顺序翻转），再从 `s2` 弹出。每个元素最多进出栈两次，均摊 O(1)（SCP2026 考过输出序列）。

!!! tip "出栈序列的可能性（SCP2025 考过）"
    1~n 依次入栈（可穿插出栈），若**第一个出栈的是 $x$**，则第二个出栈的只能是 $x$ 上方已入栈的元素（$x+1,\dots,n$）或 $x$ 下方紧邻的元素 $x-1$——**绝不可能是被压在深处的元素**。
    例：第一个出 8，第二个不可能是 1（1 被 2~7 压着，要先出 2~7 才能出 1）。
    判断"出栈序列是否合法"，用栈现场模拟一遍最稳。

### 3.2 二叉树（初赛必考、考点密集）

- **完全二叉树** $n$ 个节点，叶子数 = $\lceil n/2 \rceil$（CSP-J 2025：1000 节点 → 500 叶）。
- 完全二叉树数组存储：编号 $i$ 的左孩子 $2i$、右孩子 $2i+1$、父亲 $\lfloor i/2 \rfloor$。
- 深度 $h$ 的满二叉树共 $2^{h+1}-1$ 个节点（根为第 0 层）。
- 三种遍历：前序（根左右）、中序（左根右）、后序（左右根）。
- **唯一性**：中序+前序 → 唯一；中序+后序 → 唯一；**前序+后序 → 不唯一**。
- 重建方法：后序**最后一个**（或前序第一个）是根，到中序里找到根，左边是左子树、右边是右子树，递归处理。

!!! tip "手算模板"
    已知中序 `CADBEFG` + 后序 `CBDAFGE`：
    1. 后序末尾 `E` 是根，中序中 `E` 左边 `CADB` 是左子树、右边 `FG` 是右子树；
    2. 左子树后序为 `CBDA`，末尾 `A` 是左子树的根；
    3. 递归切分，最后得到前序 `EACDBGF`。
    每步只做一件事："后序定根 → 中序分左右 → 递归"。
    （SCP2025 原题：中序 `CGEADBF` + 后序 `GECDFBA` → 前序 `ACEGDBF`，同套路。）

### 3.3 哈夫曼树与编码

- 构造：每次合并**权值最小**的两棵，新节点权值为两者之和。
- **WPL**（带权路径长度）= 所有叶子权值 × 深度之和 = 编码总长度。例：权值 10,12,15,20,25 的 WPL = 186（CSP-J 2025 原题）。
- 哈夫曼编码是**前缀码**（任一编码不是另一编码的前缀）、变长，越常用的字符编码越短。
- 编码"种类数"：内部节点左右子树可互换 → $2^{\text{内部节点数}}$ 种（如 6 个字符、5 个内部节点 → 32 种，SCP2026 考过）。

!!! warning "易错点"
    WPL 是"加权路径长度之和"，不是叶子个数、也不是树高。合并到只剩一棵树时，**叶子总在下方**。

### 3.4 二叉搜索树 BST

- 性质：**中序遍历 = 升序序列**。据此可由"后序 + 升序"还原树并推出前序（CSP-S 2025 考过类似，J 组了解即可）。
- 理想情况增删查 O(log n)，退化成链时 O(n)。

### 3.5 图（J 组只考概念）

- **度数**：无向图所有顶点度数和 = 2×边数；有向图**入度和 = 出度和 = 边数**（CSP-J 2025 单选）。
- 存储：邻接矩阵（$O(n^2)$ 空间，判边 O(1)）vs 邻接表（$O(n+m)$ 空间，遍历邻居快）。稀疏图用邻接表。
- 邻接矩阵求度数：**数该行/列中 1 的个数**即可（无向图对称，数一行即可；SCP2025 考过）。
- 连通块：并查集或 BFS/DFS 数。邻接表**每条边两端都出现**是"可能是无向图"的必要条件。

## 4. 算法

### 4.1 枚举与模拟

- 枚举是最朴素的算法，先想"暴力能不能过"，再考虑优化。
- 模拟题务必读清操作顺序、边界条件（"第 1 轮 vs 第 0 轮"这类坑）。

### 4.2 排序

- **冒泡排序交换次数 = 逆序对数**（CSP-J 2025：`{6,1,5,2,4}` 冒泡升序需 6 次）。
- 选择排序不稳定；快排最坏 O(n²)、平均 O(n log n)；归并稳定；计数排序 O(n+k) 适用于值域小。

!!! tip "逆序对速算"
    对每个元素数"它后面有几个比它小"再求和。`{6,1,5,2,4}`：6 后面有 4 个、5 后面有 2 个 → 4+2=6。

!!! tip "快排三件套（SCP2025 考过）"
    快排是**分治 + 基于交换**的排序；平均 $O(n\log n)$，**最坏 $O(n^2)$**（如原本有序、每次划分失衡）。
    `sort` 是 STL 的排序函数，实现结合了快排 + 堆排 + 插入排序（内省排序），最坏也能做到 $O(n\log n)$。

### 4.3 二分（含二分答案）

- 二分答案三步：① 写判定函数 `check(x)`；② 二分枚举答案；③ 找"满足条件的最小/最大 x"。
- 模板要点：`mid = l + (r-l)/2`（**防溢出**）；`while (l < r)`；`check(mid)` 为真则 `r = mid`，否则 `l = mid + 1`（求最小可行值）。
- 若是"求最大可行值"，要用上取整 `mid = (l+r+1)/2` 且 `l = mid`，否则死循环。

!!! warning "易错点"
    - `(l+r)/2` 在 $l,r$ 接近 $2^{31}$ 时会溢出，务必写 `l + (r-l)/2`。
    - 二分答案右边界取**值域上界**（如 $2\times10^9$），别取成 $n$ 或数组末元素（除非已排序）。

!!! tip "二分查找次数（SCP2025 考过）"
    100 个元素的有序表二分查找，**恰好 5 次找到**的元素有 $2^4=16$ 个：第 1 次命中中点，之后每轮把区间对半，能"恰好第 $k$ 次命中"的位置是第 $k-1$ 轮划分出的新区间中点，共 $2^{k-1}$ 个。

### 4.4 贪心

- 贪心只在"局部最优 = 全局最优"时正确，需要验证或证明。
- 经典反例：**LIS 不能贪心**"每次取比上一个大且最小的数"，如 `{3,1,2}` 的 LIS 是 2，从 3 开始贪只有 1（SCP2026 考过）。
- 正确贪心例：活动安排（按结束时间排序）、哈夫曼、区间选点。

### 4.5 搜索 DFS / BFS

- DFS：递归 + 回溯，注意剪枝；BFS：队列，边权为 1 时**第一次到达即最短路**。
- 状态设计：把"位置 + 已用次数"等作为状态（如 `dis[x][y][k]`，SCP2026 迷宫传送题：步行 1 步 + 传送 1 步，三维 BFS）。
- 连通块、迷宫可达性：DFS/BFS 均可（Flood Fill）。

### 4.6 动态规划（J 组考得不深但必考）

| 类型 | 状态定义 | 转移要点 |
|:-----|:---------|:---------|
| LIS | `dp[i]` 以 $a_i$ 结尾 | `dp[i] = max(dp[j])+1`（$a_j<a_i$），O(n²) |
| LCS | `dp[i][j]` | 字符相等 `dp[i-1][j-1]+1`，否则取 max |
| 0-1 背包 | `dp[j]` 容量 j | **容量倒序**枚举 |
| 路径计数 | `dp[i][j]` | `dp[i][j] = dp[i-1][j] + dp[i][j-1]` |

- 路径计数本质是组合数：8×8 棋盘从 (1,1) 到 (4,5) 需走 3 下 + 4 右共 7 步，选 3 步向下 = $C(7,3)=35$（CSP-J 2025 原题）。

!!! tip "DP 口决"
    先想清楚"状态是什么、从哪几个方向转移来"，再写循环；边界（`dp[0]`）单独初始化。

### 4.7 前缀和 / 差分（大纲 2025 新增考点）

- 前缀和：预处理后 O(1) 求区间和。
- 差分：O(1) 区间加，最后求前缀还原原数组。

### 4.8 数论入门

- 素数判定试除法：只需试到 $\sqrt n$，条件写 `i <= n/i`（避免 `i*i` 溢出）；**1 不是素数**，`isPrime(1)` 必须返回 false（SCP2026 考了此 bug 的后果）。
- 辗转相除法：`gcd(a,b) = gcd(b, a%b)`。
- 埃氏筛 / 线性筛：快速筛素数。
- **欧拉筛（线性筛）**：每个合数被**最小质因子**筛到恰好一次，$O(n)$。常配合数组记录"最小质因子"（SCP2025 阅读程序考过：`comp_by[x*prime] = prime`，且 `x % prime == 0` 时 break）。
- C++ 取模：`-7 % 3 == -1`（结果的符号与被除数一致），别想当然。

### 4.9 摩尔投票（2025 刚考过，别忽略）

- 用于找出现次数 > n/2 的"众数"：计数抵消法——候选者 `count` 增/减，`count==0` 换候选。
- CSP-J 2025 完善程序第 2 题考了它的变体（"精明与糊涂"指认问题）。

### 4.10 倍增（binary lifting，J 组大纲考点）

- 思想：预处理"跳 $2^k$ 步到哪"（`up[i][k]`），询问时按 $k$ 的二进制位逐位跳。
- 递推：`up[i][k] = up[ up[i][k-1] ][k-1]`；跳 $k$ 步用 `(k >> j) & 1` 判断第 $j$ 位是否要跳（SCP2025 完善程序考过"从 x 跳 k 次后的位置"）。
- 同构应用：LCA 的倍增、ST 表、快速幂。

## 5. 数学（初赛分值占比高）

### 5.1 排列组合

- 加法原理（分类）、乘法原理（分步）。
- 组合数 $C(n,k)$、杨辉三角即组合数表。
- **相对顺序固定**的元素视作"相同元素"，用组合数选位置：奇数 `{1,3,5}`、偶数 `{2,4,6}` 各自顺序固定 → $C(6,3)=20$（SCP2026 考过）。
- "至少有一个"用**补集**：总数 − 不满足的。5 男 4 女选 4 人且男女都有 = $C(9,4)-C(5,4)-C(4,4)=120$（CSP-J 2025 原题）。

!!! warning "易错点"
    排列和组合别混：**与顺序有关用 P，与顺序无关用 C**。分组后乘以组内排列就是"先分组再排列"。

!!! tip "带限制的选人（先分类再计数）"
    如"5 名教师、6 名学生选 5 人，至少 1 名教师且至少 2 名学生，且甲、乙不能同时入选"（SCP2025-S 考过，答案是 345）：
    先按"教师数"分类（1 师 4 生、2 师 3 生、3 师 2 生），每类用组合数相乘，再减去"甲、乙同时入选"的违规方案。**分类讨论是这类题的通法**。

### 5.2 容斥原理

- 两集合：$|A\cup B|=|A|+|B|-|A\cap B|$。
- 三集合：$|A\cup B\cup C|=\sum|A_i|-\sum|A_i\cap A_j|+|A\cap B\cap C|$（**加奇减偶**）。
- 整除计数：$1\sim n$ 中 $k$ 的倍数有 $\lfloor n/k \rfloor$ 个。
- 综合题："1~200 中能被 3 或 5 整除但不能被 7 整除"：先算 $|A\cup B|=66+40-13=93$，再减去其中被 7 整除的 13 个 → 80（SCP2026 考过）。

!!! warning "易错点"
    减"且不能被 7 整除"时，要在 $A\cup B$ 内部做容斥（$|(A\cup B)\cap C|=|A\cap C|+|B\cap C|-|A\cap B\cap C|$），别直接 $\lfloor 200/7\rfloor=28$。

### 5.3 取整与模

- `floor` 向下、`ceil` 向上、C++ 整除向零取整（负数时与 floor 不同）。

### 5.4 斐波那契与周期

- 斐波那契数列取模后**一定存在循环节**（皮萨诺周期）。
- CSP-J 2025 原题：$f_0=f_1=1,\ f_n=(f_{n-1}+f_{n-2})\bmod 7$，周期为 16，$2025\bmod 16=9$，$f_9=6$。

!!! tip "见到大下标 + 取模"
    第一反应就是"找循环节"：把模数的周期背下来或现场快速列出前 ~2 个周期即可。

### 5.5 概率初步（几何概型偶尔考）

- 木棍折两刀成三段、能构成三角形的概率 = $\frac14$（SCP2025 考过）：能构成三角形等价于"每段都小于总长的一半"，几何概型里有利区域占总体区域的 $1/4$。
- 理解：概率题先想"总体空间"与"有利空间"各占多大，再求比值，别硬背结论。

## 6. 阅读程序与完善程序应试技巧

### 阅读程序（40 分，拿分大头）

1. **先读 main 和变量声明**，再读函数，判断程序"整体在做什么"（排序？DP？搜索？模拟？）。
2. 判断题：用**边界值 / 特殊值**（0、1、n、全相同）代入验证，别硬推大输入。
3. 单选题"输出是什么"：**手算小样例**，算完对照选项。
4. 多选题（通常最后一小问，4 分）：逐项分析，用排除法。
5. 高频考法："修改某行后输出是否变化"——重点盯循环边界（`i<n` vs `i<=n`）、比较符号（`<` vs `<=`）、初始值。
6. 模拟卷常把"算法题伪装成代码"：**欧拉筛（线性筛）、倍增、计数 DP**——先说出"这段代码在算什么"，再逐问作答（SCP2025 三篇阅读分别是位运算统计、计数 DP、欧拉筛）。

!!! warning "易错点"
    - 注意函数写得不严谨的副作用：`isPrime(1)`、空栈 `top()`、数组越界这类"语义错误"。
    - `1e9` 这种"不可达"大值：只有当所有路径代价都小于它时，换更大的值输出才不变。

### 完善程序（30 分）

1. **先通读全程序**确定算法框架（枚举 / 二分 / BFS / DP / 贪心）。
2. 填每个空时结合上下文：变量命名、注释、循环范围、数组大小。
3. 重点检查：循环边界、比较符号、下标偏移（`i-1`/`i+1`）、是否 `+1`、取模、数据类型。

!!! tip "经验"
    完善程序大多数空**靠语义就能直接推出**：比如"统计不超过 x 的个数"就是 `a[i] <= x`，返回是否满足就是 `k <= c`（SCP2026 第 k 小二分题）。把 5 个空当成一个整体来读，不要孤立猜。

## 8. 经验之谈

1. **初赛考的是"范围广、深度浅"**：把大纲里每一项都过一遍，不要只盯复赛算法（复赛不考的进制、二叉树、哈夫曼恰恰是初赛送分题）。
2. **手算能力是核心竞争力**：进制、二叉树遍历、哈夫曼 WPL、排列组合、容斥必须能手算，且要算得快。
3. **错题本记"为什么想错"**：比如把"顺序固定"想成排列、把补码按原码算——比记正确答案更有用。
4. **时间分配 + 先易后难**：阅读程序是分数大头，别在单选最后一两题上耗死。
5. **验证胜过记忆**：二叉树公式、组合数、周期题，拿小数据现场算一遍最稳。
6. **模拟赛偏难不必焦虑**：SCP2026-J1 难度高于真实 CSP-J 初赛，用它练手时重点看"知识点覆盖"而非分数。
7. **代码修改题是保分项**：SCP2025 三篇阅读的判断题几乎全是"删某行/改某条件/改数据类型，输出变不变"——只需盯"会不会越界、会不会溢出、会不会少算/多算"三类问题。
